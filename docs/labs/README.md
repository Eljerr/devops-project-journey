# docs/labs — Bukti Mentah Eksperimen

Setiap lab dicatat di sini memakai `docs/templates/lab-session-template.md`.
Nama berkas: `lab-<fase>.<sub>-<nn>-<judul-singkat>.md` (contoh: `lab-1.1-01-oom-swap-matrix.md`).

Berkas di folder ini adalah **sumber kebenaran tertinggi** (`[LAB ✓]`) untuk agen AI dan untuk dokumen lain.
Jangan memoles output terminal di sini.
